# 🧠 1️⃣ Array & Hashing (Most Asked Ever)

If you master this section, you already clear 40% of interviews.

### Must Know:

- Two Sum

- 3Sum

- Kadane’s Algorithm (Maximum Subarray)

- Prefix Sum

- Sliding Window

- Two Pointers

- Merge Intervals

- Product Except Self

- Subarray Sum = K

### Core Patterns:

- HashMap lookup trick

- Running prefix sums

- Expanding/contracting window

- Sorting + two pointer sweep

# 🔁 2️⃣ Binary Search (Interviewers LOVE This)

Not just “search in sorted array”.

### Must Know:

- Lower bound / Upper bound

- Search in rotated array

- Find peak element

- First & last occurrence

- Binary search on answer
  - Allocate minimum pages

  - Koko eating bananas

  - Capacity to ship packages

### ⚡ Pro tip:

If question says `“minimum possible”`, `“maximum possible”`, `“smallest such that”` → **70% chance** it’s binary search on answer.
